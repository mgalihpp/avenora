# avenora

A Next.js starter generated by [starter-gen](https://www.npmjs.com/package/starter-gen).

## Stack

- Next.js 16 (App Router, Turbopack) + React 19
- Better Auth (email/password + OAuth)
- tRPC v11 — end-to-end typesafe API
- Prisma (^6.19.0) — see `prisma/schema.prisma`
- Tailwind CSS v4 + shadcn/ui
- Biome (lint + format) + Husky pre-commit

## Getting Started

```bash
cp .env.example .env
```

Fill in `DATABASE_URL` and generate a secret:

```bash
openssl rand -base64 32
```

Put the output in `BETTER_AUTH_SECRET`. Then:

```bash
# install
bun install        # or: npm install / pnpm install

# sync the schema (dev)
bun run db:push    # or: npx prisma db push

# start
bun run dev
```

Open http://localhost:3000 — sign up, then you land on the dashboard.

## Environment Variables

| Variable | Required | Description |
| --- | --- | --- |
| `DATABASE_URL` | ✅ | Database connection string |
| `BETTER_AUTH_SECRET` | ✅ | `openssl rand -base64 32` |
| `BETTER_AUTH_URL` | ✅ | e.g. `http://localhost:3000` |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | ⬜ | Google OAuth |
| `GITHUB_CLIENT_ID` / `GITHUB_CLIENT_SECRET` | ⬜ | GitHub OAuth |

## Scripts

| Command | Action |
| --- | --- |
| `bun run dev` | Start dev server (port 3000) |
| `bun run build` | Production build |
| `bun run start` | Start production server |
| `bun run lint` | Biome check |
| `bun run format` | Biome format --write |
| `bun run fix` | Biome check --write |
| `bun run db:push` | Push schema to the database |
| `bun run db:generate` | Regenerate Prisma Client |
| `bun run db:studio` | Open Prisma Studio |
| `bun run db:seed` | Run `scripts/seed.ts` |

## Structure

```
app/                          # App Router routes
  (marketing)/                # public landing
  (auth)/                     # signin / signup
  (dashboard)/                # protected pages
  api/auth/[...all]           # Better Auth handler
  api/trpc/[trpc]             # tRPC fetch handler
components/ui/                # shadcn/ui
features/auth/                # auth feature (config, client, router, components)
server/trpc/                  # tRPC core (trpc.ts, context.ts, server.ts, routers/_app.ts)
lib/db.ts                     # Prisma client singleton
lib/trpc/                     # tRPC client, provider, server caller
prisma/schema.prisma          # database schema
```

## Conventions

- All DB access goes through the tRPC backend.
- `@/*` maps to the project root.
- Validation uses Zod on tRPC inputs.
- Biome is the single linter/formatter; pre-commit runs `biome check --staged`.
